# 🍃 Matchally — El ritual de la calma

Bienvenido/a a Matchally, un espacio digital diseñado para compartir la tradición del té matcha, ofreciendo el mejor matcha de ceremonia hasta accesorios artesanales. Este sitio nació como parte de mi formación en Desarrollo Web, con el objetivo de crear una experiencia minimalista, estética y funcional.

---

### Tecnologías aplicadas
El proyecto combina estructura, diseño y lógica interactiva:

* **HTML5 Semántico:** Para una estructura organizada y accesible.
* **CSS3 Moderno:** Implementación de Flexbox para la grilla de productos, Media Queries para el diseño responsivo y efectos visuales personalizados.
* **JavaScript:** Lógica de interacción para el carrito y dinamismo general del sitio.
* **Iconografía y Tipografía:** Uso de FontAwesome para la interacción social y Google Fonts (Lato, Montserrat e Instrument Serif) para mantener una identidad visual coherente.

---

### Funcionalidades principales
* **Gestión de datos persistente:** Implementación de la Web Storage API (`localStorage`) para mantener el estado del carrito de compras entre sesiones y páginas.
* **Comunicación externa:** Integración con la API de Formspree para el procesamiento y envío seguro de datos del formulario de contacto sin necesidad de un backend propio.
* **Atención al cliente vía WhatsApp:** Integración con la API de WhatsApp para facilitar la comunicación directa y personalizada con los usuarios.

---

### Navegación responsiva
Diseño 100% adaptable, pensado para que la experiencia sea igual de cómoda tanto en móviles como en computadoras, utilizando CSS avanzado.
